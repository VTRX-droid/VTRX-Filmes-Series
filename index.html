Sobre o projeto

O VTRX Filmes & Séries é um aplicativo Android desenvolvido para Android TV e TV Boxes.

O projeto apresenta informações sobre filmes e séries, incluindo cartazes, gêneros, lançamentos e sinopses.

Desenvolvido para uso pessoal e não comercial.

VTRX ENTERTAINMENT

Este produto utiliza a API do TMDB, mas não é endossado nem certificado pelo TMDB.
